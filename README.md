# Mariangell Cabrera

# Nombre del proyecto = "CALLING"

## Descripción

Este es un videojuego 2D de terror y exploración. El jugador deberá recorrer un entorno misterioso, descubrir qué ocurrió y avanzar mientras enfrenta diferentes situaciones dentro del juego.

## Integrantes

- Mariangell Cabrera
- Oscar Henriquez

## Funcionalidades
- Movimiento del jugador
- Exploración del mapa
- Cámara que sigue al jugador
- Menú
